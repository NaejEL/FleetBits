# Every version below is pinned exactly. The four marked (1) and (2) moved
# together, as one set, because they cannot move apart:
#
# (1) `fastapi>=0.116.0` floated onto FastAPI 0.141, which registers the routes
#     of include_router() as _IncludedRouter objects. prometheus-fastapi-
#     instrumentator 7.0.0 cannot name those and raises AttributeError on every
#     request through its middleware — 60 of 89 tests failed on a fresh install.
#     Instrumentator 8.x fixes it and requires starlette 1.x.
# (2) starlette 0.49.1, python-multipart 0.0.22 and pytest 8.3.5 carried 22
#     known CVEs between them (pip-audit, the pre-commit hook of this repo):
#     Host-header URL reconstruction, several parser denial-of-service issues,
#     and the pytest /tmp permission issue. The fixed versions are starlette
#     1.3.1+, python-multipart 0.0.31 and pytest 9.0.3 — so the starlette bump
#     that (1) needs is also the one the CVEs need.
#
# pip-audit on this file: no known vulnerabilities.
# Verified with `./.venv/bin/python -m pytest` on Python 3.12, the interpreter
# the Dockerfile and the workflows use.
# ─────────────────────────────────────────────────────────────────────────────
